# Neurolink Guidance

A web application developed for escaping eleven.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

```sh
# Clone the repository
git clone https://github.com/euginjoy007/neurolink-guidance.git

# Navigate to the project directory
cd neurolink-guidance

# Install dependencies
npm install

# Start the development server
npm run dev
```
